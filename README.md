# dotasks

面向**长工期任务**的文件化任务管理 Skill：让 Agent 在任何一次新会话里都能在 30 秒内恢复到上次的现场，不出现断点、不丢失上下文。

## 解决什么问题

长任务跨多个 session 时，常见失效模式：

- 只记录了"要做什么"，没记录"做到哪、为什么这么做"
- 新会话不知道从哪继续，用户被迫反复复述背景
- 并发写入撞 id、日志漏写、隐私信息被原样落盘

dotasks 用三个纯文本文件解决它：**任务状态** + **进展事件流** + **阶段快照**。

## 三类文件

| 文件 | 回答的问题 | 写入方式 |
|------|-----------|---------|
| `tasks.jsonl` | 要做什么？什么状态？ | 追加为主，单行改动用 edit |
| `progress.jsonl` | 做到哪了？为什么这么做？ | 纯追加，永不修改 |
| `checkpoints/` | 这一刻的完整现场是什么？ | 每次新增一个文件 |

目录结构：

```
.dotasks/
├── tasks.jsonl
├── progress.jsonl
├── checkpoints/
│   └── 20260608T160000-cp01.json
├── archive.jsonl
└── .backup/
```

## 核心流程

| 流程 | 触发 | 作用 |
|------|------|------|
| **resume** | "继续上次的任务" / 新会话开工 | 读三个文件 → 输出现场摘要 + 下一步 |
| 添加任务 | "记件事：X" | 脱敏后追加到 tasks.jsonl |
| 更新状态 | "X 做完了" | 改任务行 + 追加 progress 事件 |
| checkpoint | "存个档" | 生成阶段现场快照，含 next_step |
| 归档 | "清一下已完成" | 移入 archive.jsonl，不物理删除 |
| 回顾 | "回顾一下今天" | 按时间线输出 progress |

## 相比 v1 的改进

**P0（原设计目标无法达成的部分）**

- 新增 `progress.jsonl` 进展事件流与 `checkpoints/` 阶段快照——原来的文件只存"任务存在"，不存"执行上下文"
- 新增 **resume 恢复流程**，明确"会话开始时怎么把状态读回来"，补齐断点续接最后一公里
- 修正写入模型：原文档的 "write 追加写入（append 模式）" 不存在（write 覆写全文），会直接清空历史；改为"追加用 read 全文+覆写"或"单行改动用 edit 并保证 old_string 唯一"

**P1（结构性缺陷）**

- 新增 `parent` / `depends_on` / `priority`，支持任务拆解与依赖
- id 由 `max+1` 改为 `时间戳+随机后缀`，消除并发撞号，并加入唯一性校验
- 补全状态机（`idea/pending/in_progress/blocked/done/cancelled`）与转换规则，明确 `resolved` 与 `status` 的一致性约束
- "agentTurn 结束时自动写日志"改为"显式 checkpoint 时写"——Agent 没有 turn_end 钩子，且无法取得 tokens 字段
- 新增 `schema` 版本号字段，为后续结构迁移留路

**P2（隐私）**

- 脱敏范围从"仅日志"扩展到**全部文件**，重点覆盖 `tasks.jsonl` 的 `content`
- 补齐中国大陆高频 PII：手机号、身份证、银行卡、邮箱、统一社会信用代码
- 删除不合理规则"缩减超 50% 整条替换为 `[PRIVACY_FILTERED]`"（字符缩减比例与隐私强度无关，会误杀正常内容）
- 清理改为**归档而非物理删除**，且覆写前自动备份

**P3（工程与可用性）**

- 明确全局 / 项目级路径的优先级判定规则（原文档只列表未定规则）
- 明确时间戳必须用系统命令获取，禁止手写推算
- 精简 `allowed-tools`：v1 的 `exec` 正文未使用，`memory_get` 未出现
- 声明与平台内置任务工具、MEMORY 的**边界与不重复记账原则**
- 补负例（"什么情况下不要读写文件"）与统一输出模板

## 安装

把本目录放到 skill 目录下即可，例如：

```bash
# 用户级（所有项目可用）
cp -r dotasks ~/.workbuddy/skills/dotasks
```

## 快速上手

```
你：记件事：把 XX 模块的迁移方案定下来
你：（干一段活之后）存个档
你：（下次新会话）继续上次的任务
```
